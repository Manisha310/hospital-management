# hospital-management

## Project Overview

The Hospital Management System is a web-based application developed to simplify and automate hospital operations. The system helps manage patient records, doctor information, appointments, room allocation, and payments efficiently.

This project was developed using Java for backend development and HTML, CSS, and JavaScript for frontend development.

---

## Technologies Used

### Backend
- Java
- JDBC
- MySQL

### Frontend
- HTML5
- CSS3
- JavaScript

### Database
- MySQL

### Development Tools
- Eclipse/IntelliJ IDEA
- Apache Tomcat
- Git & GitHub

---

## Modules

### 1. Doctor Management
- Add Doctor
- Update Doctor Details
- View Doctor Information
- Manage Doctor Specializations

### 2. Outpatient Management
- Register Outpatients
- Maintain Patient Records
- Track Consultation Details
- View Patient History

### 3. Inpatient Management
- Admit Patients
- Discharge Patients
- Manage Admission Details
- Track Hospital Stay Information

### 4. Appointment Management
- Schedule Appointments
- View Appointment Details
- Update Appointment Status
- Manage Doctor Availability

### 5. Room Allocation Management
- Allocate Rooms to Patients
- Track Room Availability
- Update Room Status
- Manage Bed Allocation

### 6. Payment Management
- Generate Bills
- Record Payments
- View Payment History
- Manage Billing Details
